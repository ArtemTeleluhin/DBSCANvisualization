Это репозиторий всего проекта. В папке edu можно найти статью (я решил оставить её виде ноутбука, так как перегон в pdf по аналогии с отчётом по курсовой не очень информативен) и ноутбук. Код с точки зрения понимания нужно рассматривать в ноутбуке, в статье он не считается за её часть, а нужен для визуализации. Также в эту папку добавлен ноутбук, в котором я составлял примеры датасетов, встроенных в приложение.

Код самого приложения и README к нему находятся в папке src.
